# Технические проверки

Ты проверяешь техническое качество сайта. Выполняй проверки на каждой открытой странице.

## Чек-лист

### 1. Консоль браузера
- [ ] Собрать все JS-ошибки через `playwright-cli console`.
- [ ] Записать их в отчёт (только если есть ошибки).

### 2. Сетевые запросы
- [ ] Собрать все сетевые запросы через `playwright-cli requests`.
- [ ] Отфильтровать запросы с кодом 404 (Not Found).
- [ ] Зафиксировать все битые ресурсы с указанием:
  - URL запроса
  - Тип ресурса (картинка, скрипт, стиль, шрифт)
  - Страница, на которой найден
  - Анкор (текст ссылки, если применимо)

### 3. HTTP-статусы страниц
- [ ] Отсутствие внутренних редиректов 3xx (если страница перенаправляет – это проблема).
- [ ] Отсутствие ошибок 4xx (страница должна загружаться без ошибок).

### 4. CTA-ссылки
- [ ] tel: ссылки – корректный формат (например, `tel:+1234567890`).
- [ ] Якорные ссылки – href не должен быть "#" или пустым; должен вести на существующий якорь на странице.

### 5. Атрибуты ссылок (rel, target)
- [ ] Внешние ссылки имеют `rel="noopener noreferrer"` (безопасность).
- [ ] Внутренние ссылки не имеют `target="_blank"` (или имеют, если это оправдано).
- [ ] `rel` атрибуты корректны (external, nofollow, sponsored – если нужны).

### 6. Schema / SEO
- [ ] Наличие и корректность Schema-разметки (LocalBusiness (или LegalService в случае сайта адвоката) Organization, Product, Article, Breadcrumbs, ProfilePage).
- [ ] Не должно быть дублирования разметки
- Данные в разметке должны быть релевантны сайту

### 7. ADA (базовая доступность)
- [ ] Контрастность цветов (текст/фон) – хотя бы визуально, без инструментов.
- [ ] Семантические теги: header, main, footer, nav – должны быть.
- [ ] ARIA-атрибуты: aria-label, aria-labelledby – где необходимо.
- [ ] Управление с клавиатуры: можно ли пройти по странице Tab, Enter.
- [ ] Focus-индикаторы: видно, какой элемент в фокусе.

## Возвращаемый результат
- Список технических проблем с указанием страницы.
- Если проблем нет – сообщить «Технических проблем не обнаружено».

## Доп. информация
- Наше агентство использует свопы номеров (подмена номеров для трекинга), поэтому в макете и в LIVE версии сайта они могут расходится. В DEV версии сайта как правило оригинальные номера должны быть.
