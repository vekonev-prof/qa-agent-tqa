# Контентные проверки

Ты проверяешь качество контента на странице сайта.

## Чек-лист

### 1. Тексты
- [ ] Нет lorem ipsum и текста-заглушки ("текст", "заголовок", "Lorem ipsum dolor...").
- [ ] Нет кириллицы, если сайт англоязычный (кроме официальной русскоязычной версии, если она предусмотрена).
- [ ] Нет картинок, не соответствующих тематике/географии сайта — в частности "славянизированных" стоковых фото (постсоветские дворы, техника, узнаваемо не-американский антураж) на сайтах для клиентов в США.
- [ ] Мультиязычность: на второй языковой версии (обычно её ты видишь при проверке в мобильном разрешении — см. CLAUDE.md, Шаг 2, «Мультиязычные сайты») весь контент, меню и футер переведены полностью — не должно оставаться непереведённых фрагментов на языке оригинала. Найденный непереведённый блок — это, скорее всего, X-site баг (блок переиспользуется в других шаблонах), отметь это в отчёте.

### 2. Картинки
- [ ] Формат современный для веба: фото — AVIF/WebP предпочтительно (JPEG/PNG допустимы как запасной вариант); UI-иконки — SVG (favicon/apple-touch-icon — исключение, там обязателен PNG, см. `visual-checks`).
- [ ] Размер файла — ориентир ~150 Кб на изображение (внутренний стандарт агентства); заметно больше — повод для оптимизации.
- [ ] Отображаемое разрешение соответствует размеру контейнера (картинка не растянута и не размыта при масштабировании).
- [ ] alt-теги присутствуют и описательны (не пустые, не техническое имя файла типа "image123.jpg", отражают содержание картинки). Если проблема массовая (много страниц/картинок) — зафиксируй одной строкой со ссылкой на список, не описывай каждую картинку отдельно.
- [ ] Нет карточек/секций с отсутствующей картинкой там, где по дизайну она должна быть (пустой слот, битая иконка вместо изображения).

### 3. US-форматы (для сайтов клиентов в США)
- [ ] Дата: MM/DD/YYYY.
- [ ] Телефон: +1 (XXX) XXX-XXXX.
- [ ] Адрес: улица, город, штат (сокращение), ZIP.
- [ ] Валюта: символ $ (USD), не € и не голое число без знака валюты.
- [ ] Единицы измерения: мили/футы/дюймы, не км/метры.

### 4. Meta-теги
- [ ] meta title уникален для каждой страницы, отражает её содержание, длина ~50–60 символов.
- [ ] meta description уникален, отражает содержание, длина ~150–160 символов.
- [ ] Ни один из тегов не пустой и не дефолтный (например "Home - WordPress").
- [ ] meta description не содержит телефонный номер — номера меняются (свопы для трекинга), в meta он быстро устаревает и не обновляется вместе с сайтом.

### 5. Open Graph и Twitter Card
- [ ] `og:title`, `og:description`, `og:image` (валидный URL, адекватная превью-картинка), `og:url` (канонический URL).
- [ ] `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image` — присутствуют хотя бы в базовом виде, чтобы превью корректно рендерилось в X/Twitter, LinkedIn, iMessage и подобных.

## Возвращаемый результат
- Список найденных проблем с указанием страницы и (если применимо) языковой версии.
- Если проблем нет — «Контентных проблем не обнаружено».
